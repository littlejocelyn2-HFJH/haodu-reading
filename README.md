# 好讀・讀報日記（haodu-reading）

國中讀報課的「十分鐘讀報日記」：讀報計時、報紙版面、閱讀理解題（擷取／推論／統整／評鑑）、本期前三名與原因、讀後自評、閱讀能力圖、認真獎章。

- 網頁：`https://littlejocelyn2-hfjh.github.io/haodu-reading/`
- 教師端：網址後面加 `#teacher`；大屏：加 `#screen`（都要教師密碼）

## 檔案
- `index.html`：網頁（題目、版面清單都在這裡）
- `config.js`：`sheetApi` 填 Apps Script 的 `/exec` 網址（留空＝本機模式）
- `apps-script/Code.gs`：後端程式範本（**不含學生姓名與舊資料**；老師實際使用的完整版在私人備份）

## 一、開啟 GitHub Pages
Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 **main / (root)** → Save。約 1 分鐘後網址生效。

## 二、Apps Script（收資料）
1. 打開試算表「好讀讀報日記資料」→ 擴充功能 → Apps Script。
2. 貼上 Code.gs，**改第 8 行教師密碼**（保持 `change-me` 會一律登入失敗），儲存。
3. 部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署（網址不變）。
4. 直接打開 `/exec` 網址看到 `{"ok":true,...}` 是正常的，那是後端。
5. **之後只要改了 Code.gs**：重新貼上、再改一次密碼、用「新版本」重新部署。

版面圖放在老師雲端硬碟的「好讀讀報版面」資料夾（不用分享），由 Apps Script 讀取，不公開在 GitHub。

## 三、老師檢視
- 試算表「讀報資料」：程式用（每人每期一列）。「作答紀錄」：每次送出一列，可直接篩選。
- 教師端：班級繳交、學生類型（認真／快答／敷衍／待支援，可修改）、認真獎章、疑似亂答提醒、每則原因、⭐ 選示範、📺 大屏（每 15 秒更新，不顯示敏感資料）、🧪 教師試作（不記錄）、📋 題目檢查、匯入成績碼、清除某班資料。

## 注意
- 學生進站填班級、座號、姓名，存在瀏覽器，下次自動帶入；不需登入任何帳號。
- 送出失敗時畫面會給「成績碼」，老師可在教師端匯入。
- 疑似亂答（用時少於門檻、或全選同一選項且未全對）只是提醒，請老師確認。
